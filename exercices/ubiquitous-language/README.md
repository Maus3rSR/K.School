## Prérequis

- [Deno](https://deno.land/) installé (`deno --version`)
- Avoir suivi le cours Ubiquitous Language

> Lancer depuis la racine `exercices/ubiquitous-language/` avec `deno task <exercice>`, ou directement depuis le dossier de l'exercice avec `deno task start`.
