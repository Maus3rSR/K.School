# Lexique

::left::

<TermCard term="Component" translation="(Composant)" definition="Fonction JavaScript qui retourne du JSX et représente une partie de l'UI" />

<TermCard term="Composition" definition="Imbriquer des composants les uns dans les autres pour construire des interfaces complexes" />

<TermCard term="Fragment" definition="Wrapper vide `<>...</>` permettant de retourner plusieurs éléments sans balise HTML supplémentaire" />

<TermCard term="JSX" definition="Syntaxe JavaScript permettant d'écrire du markup HTML-like directement dans le code" />

::right::

<TermCard term="Leaf component" translation="(Composant feuille)" definition="Composant sans enfants, souvent réutilisable, en bas de l'arbre de rendu" />

<TermCard term="PascalCase" definition="Convention de nommage où chaque mot commence par une majuscule — obligatoire pour les composants React" />

<TermCard term="Render tree" translation="(Arbre de rendu)" definition="Représentation hiérarchique des composants React affichés lors d'un rendu" />

<TermCard term="Root component" translation="(Composant racine)" definition="Premier composant rendu par React, point d'entrée de l'arbre de rendu" />
