# Lexique

::left::

<TermCard term="Assertion" definition="Vérification qu'un résultat correspond à la valeur attendue dans un test" />

<TermCard term="Baby Steps" definition="Avancer par petites modifications minimales, un test à la fois" />

<TermCard term="Fake" definition="Implémentation simplifiée mais fonctionnelle d'une dépendance (ex: base de données en mémoire)" />

<TermCard term="Fixture" definition="Jeu de données de test réutilisable pour initialiser plusieurs tests dans le même état" />

::right::

<TermCard term="Red-Green-Refactor" definition="Le cycle TDD : test qui échoue → code minimal → amélioration" />

<TermCard term="Regression" translation="(Régression)" definition="Bug réapparu dans du code qui fonctionnait avant une modification" />

<TermCard term="Stub" definition="Dépendance de test qui retourne toujours une valeur fixe prédéfinie" />

<TermCard term="Test Unitaire" translation="(Unit Test)" definition="Test isolé vérifiant le comportement d'une seule unité de code" />
