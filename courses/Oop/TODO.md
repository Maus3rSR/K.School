## 🎯 Notes Techniques

### Conventions utilisées
- **Langage** : TypeScript (avec typage explicite)
- **Layouts** : `two-cols-header` avec `layoutClass: gap-x-4`
- **Animations** : 
  - `v-click="N"` pour synchroniser avec line-highlighting
  - Shiki Magic Move pour montrer l'évolution du code
  - Line highlighting `{1-7|1|2-3|all}` pour décortiquer le code

### Points pédagogiques à respecter
- Partir du concret (problème quotidien) vers l'abstrait (concept POO)
- Un concept par slide
- Exemples réalistes avec pseudo-code complexe
- Synchronisation des explications avec le code surligné
