# Lexique

::left::

<div v-click>

**Classe** : Modèle définissant la structure et le comportement

**Objet** (ou Instance) : Réalisation concrète d'une classe

**Attribut** (ou Propriété) : Donnée d'une classe

**Méthode** : Comportement/action d'une classe

**Constructeur** : Méthode spéciale d'initialisation

**Encapsulation** : Cacher les détails d'implémentation

</div>

::right::

<div v-click>

**Héritage** : Réutiliser et étendre une classe

**Polymorphisme** : Traiter des objets différents de manière uniforme

**Interface** : Contrat définissant des méthodes à implémenter

**Classe abstraite** : Classe avec implémentation partielle

**Modificateurs d'accès** : public, private, protected

**Surcharge** : Redéfinir une méthode héritée

</div>
