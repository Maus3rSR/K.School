# Exercices VS Code

Exercices pratiques pour le cours VS Code.

## Structure

```
vscode/
├── 01-navigation/      # Naviguer sans souris
└── 02-refactoring/     # Refactoriser un fichier
```

## Installation

```bash
pnpm install
```

## Lancer les exercices

### Navigation

```bash
pnpm navigation
```

Puis ouvrez le dossier `01-navigation` dans VS Code et suivez les instructions du `README.md`.

### Refactoring

```bash
pnpm refactoring
```

Puis ouvrez le dossier `02-refactoring` dans VS Code et suivez les instructions du `README.md`.

## Vérification TypeScript

```bash
pnpm typecheck
```
