# Lexique

::left::

<TermCard term="children" definition="Prop spéciale contenant le contenu JSX placé entre les balises d'un composant" />

<TermCard term="className" definition="Attribut JSX qui applique une classe CSS, équivalent de `class` en HTML" />

<TermCard term="Default value" translation="(Valeur par défaut)" definition="Valeur utilisée par une prop quand le parent ne la fournit pas" />

<TermCard term="Destructuring" translation="(Déstructuration)" definition="Extraire directement les champs d'un objet : `{ name, size }`" />

<TermCard term="Interface" definition="Structure TypeScript qui décrit la forme et le type des props" />

::right::

<TermCard term="Optional prop" translation="(Prop optionnelle)" definition="Prop non obligatoire, marquée d'un `?` dans l'interface" />

<TermCard term="Props" definition="Données passées par un composant parent à un composant enfant" />

<TermCard term="ReactNode" definition="Type TypeScript décrivant tout contenu affichable par React" />

<TermCard term="Read-only" translation="(Lecture seule)" definition="Un enfant lit ses props mais ne doit jamais les modifier" />
