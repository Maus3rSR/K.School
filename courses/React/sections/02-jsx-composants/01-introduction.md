# Qu'est-ce qu'un composant ?
Une pièce d'UI réutilisable

Comme une **fonction** JavaScript :
- Un composant encapsule une logique (affichage + comportement)
- On l'appelle où on veut, autant de fois que nécessaire
- Il peut prendre des **paramètres** (props) pour s'adapter

<v-click>

Comme une **variable** :
- Il a un **nom** (PascalCase obligatoire)
- Il a une **valeur** (ce qu'il affiche)
- Il peut être **composé** avec d'autres

</v-click>
