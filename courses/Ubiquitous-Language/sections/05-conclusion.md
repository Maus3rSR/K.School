# Conclusion
Ce qu'on retient

<v-clicks>

- 🎯 Le bon nommage est un **outil de conception**, pas seulement de style
- 👁️ Le **métier doit être visible** dans le code, pas l'inverse
- 🧭 L'ubiquitous language _(qui provient du DDD)_ ici sert à **formaliser le vocabulaire**, sans les patterns techniques
- 🔍 Plus le **contexte métier** est clair, plus les noms sont **précis et utiles**

</v-clicks>
