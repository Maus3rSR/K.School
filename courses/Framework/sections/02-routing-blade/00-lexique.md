# Lexique

::left::

<TermCard term="Closure" translation="(Fonction anonyme)" definition="Fonction sans nom définie à la volée, souvent passée en argument à une route" />

<TermCard term="Directive" definition="Instruction Blade préfixée par @ (@if, @foreach) qui génère du PHP" />

<TermCard term="Escaping" translation="(Échappement)" definition="Neutralisation des caractères HTML spéciaux pour empêcher l'injection de code" />

<TermCard term="Layout" translation="(Gabarit)" definition="Gabarit de page partagé dont les vues héritent pour éviter la duplication" />

::right::

<TermCard term="Named route" translation="(Route nommée)" definition="Route identifiée par un nom, dont l'URL se génère avec route()" />

<TermCard term="Redirect" translation="(Redirection)" definition="Réponse HTTP qui renvoie le navigateur vers une autre URL" />

<TermCard term="Route constraint" translation="(Contrainte de route)" definition="Règle qui restreint les valeurs acceptées pour un paramètre de route" />

<TermCard term="Route parameter" translation="(Paramètre de route)" definition="Segment variable d'une URL, capturé et transmis au contrôleur" />
